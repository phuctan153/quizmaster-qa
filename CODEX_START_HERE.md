# Start or Resume Autonomous Project Work

Read `AGENTS.md`, `TASKS.md`, `docs/requirements/PROJECT_SCOPE.md`,
`docs/requirements/DECISION_LOG.md` and `docs/progress/WORKLOG.md`.
Inspect Git status and existing source before editing.

Refine tasks, implement small vertical slices, execute relevant tests, review,
maintain documentation, commit verified work and continue unblocked tasks.
The human is Product Owner and final acceptance reviewer. Product changes require
explicit approval. Never present proposals as approved or fabricate evidence.
Do not push or deploy without authorization. Preserve existing user work.

After an interruption, resume from actual repository state and the latest worklog.
Do not infer completion from plans. These documents do not create a background
service or override tool permissions. A running agent session is necessary.

Project artifacts and commit messages use English. User-facing communication
uses Vietnamese.
